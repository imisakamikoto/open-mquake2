御坂防灾（Mquake 2.0）
御坂防灾是一款地震监测客户端，将日本、中国、韩国等地的地震速报、震度观测与海啸信息汇集于统一界面，实时呈现在地图上，并在必要时发出提醒。

本软件的前身为基于 Leaflet 与 jQuery 的 Web 版本，现以 Flutter 构建界面层、以 Rust 实现计算核心，界面采用 Material Design 3 深色风格。

功能概述
震度观测。 各地测站的实时震度按颜色显示于地图，数据来源包括 K-NET、S-net、SeisJS、P-Alert、KMA，以及用户自行接入的移动设备测站。

地震预警。 收到紧急地震速报时，软件发出声音提示、弹出窗口并将地图定位至震源，绘制 P 波与 S 波扩散圈，同时计算用户所在地的预计到达时间。同一地震的多条报文仅显示最新一条，不会在面板中反复切换。

海啸信息。 海啸警报、注意报及沿岸预报区按等级着色，潮位站按实测波高绘制柱状图。

官方报文。 日本气象厅（JMA）发布的地震、震度、火山与海啸报文统一汇集于通知中心，关键字段完整呈现，并可发送至移动设备通知栏。

本地震源推算。 官方速报设有发布门槛，未达门槛的事件不会发报，震中位置因而无从获取。本软件依据测站开始摇晃的时刻自行反推震源位置，推算结果经一致性检查后才会显示；无法解释观测数据的结果不予发布。

演练模式。 地图左下角的演练面板可在无真实地震的情况下练习完整预警流程。注入的预警数据走真实处理链路，但统一标记为“演练”，不会与真实速报混淆。面板提供预设场景、311 回放、自定义震源及多报流程模拟。

测站数据
地图上的测站由多个数据源合并而成：

数据源	说明
K-NET	日本陆地强震台网
S-net	日本海底台网，默认关闭
SeisJS（Wolfx）	民间台站，实时推送
本地测站	移动设备浏览器接入
P-Alert、KMA	台湾、韩国测站
移动设备可作为临时测站使用：桌面端提供局域网地址，设备连接同一 Wi-Fi 后通过浏览器打开该地址，授予运动传感器与定位权限即可开始上传数据。此功能仅在桌面端作为接收设备时提供，移动端应用本身不包含该入口。

本地震源推算
该功能在设置中提供多个独立开关：启用推算、检知门槛自适应、本地 AI 卷积模型、自我学习、在线校准。

地图上以不同标记区分状态：暗蓝色小点为尚未摇晃的静默测站，亮青色点为已检知测站，红白十字为推算震源，白色虚线为 P 波前缘，橙红色虚线为 S 波前缘。检知点仅在图标外围添加空心环，不覆盖测站本身的震度颜色。

精度方面，合成数据条件下震中误差为 1 至 9 公里，海上单侧覆盖场景为 2 至 9 公里。真实数据的精度主要受测站时间分辨率限制：K-NET 默认每 10 秒采集一帧，同一帧内所有测站共享同一时间戳；如需更高精度，可将刷新间隔调整为 1 至 2 秒。深度为弱约束条件，台网包围时一般误差约 ±20 公里，单侧覆盖时通常只能给出上限。

海域地震主要依靠陆地台网推算，S-net 海底测站不参与本地推算。该数据源按分钟发布瓦片产品，时间戳仅精确到分钟，用于到时计算会产生“整帧同时检知”的虚假信息。

震度数值说明
各数据源的“静止”读数并不一致，本软件统一将震度下界限制为 -3。低于 -3 的数值不具备物理意义，仅为各源计测公式的噪声底；若不予限制，相关测站将无法显示，或出现每秒闪烁的现象。

KMA 发布的 진도 为修订麦加利震度（MMI），与 JMA 震度并非同一标度。本软件按对照表进行换算，避免将中等地震显示为最高档位。

平台支持
桌面端（Windows、macOS）。 最小化或关闭窗口时默认缩至系统托盘，数据源与提醒功能继续运行；右键点击托盘图标可打开主窗口或退出。支持局域网本地测站。预警、海啸或强震动触发时，窗口将弹出并置顶，20 秒后自动取消置顶，不会长期抢占焦点。

移动端（Android、iOS）。 采用整页导航，地图、列表、海啸、通知与设置同一时间仅挂载一个页面，避免切换后地图失效或黑屏。Android 默认启用“后台持续刷新”前台服务，锁屏或切换至后台时仍保持数据轮询。Android 16 及以上接入系统实时通知胶囊区域，iOS 16.2 及以上接入灵动岛与锁屏实时活动。系统不支持实时活动时，Android 保留可更新的普通通知作为兜底。

应用被系统彻底结束后无法接收推送，原因为尚未配置远程推送服务器。

首次启动
首次启动时显示四步设置向导：在地图上选定所在地（或手动输入经纬度）、选择界面与播报语言、设置提示音与震度门槛、选择数据源与地图显示内容。向导中的修改为草稿状态，点击“完成”后写入设置；“跳过”则保持原有设置。此后可在设置中重新运行向导。

测站信息卡
地图放大至一定级别后，测站旁会显示读数。缩放级别低于 8.5 时仅显示图标；8.5 至 9.4 时显示一行“站名 震度”；9.5 及以上显示三行卡片（站名、加速度、震度）。仅绘制视口内的测站，按震度降序排列，单屏最多 32 条；文字位置会避开其他文字与测站点位。

隐私说明
崩溃与错误上报默认不启用；未配置上报地址时不会发出任何请求。设备标识仅用于区分不同设备，不包含个人信息，也不会上报。开发版编译产物带有水印，正式分发版不包含水印。

已知限制
本地推算精度受测站时间分辨率影响。深度仅能提供近似值。海域地震主要依靠陆地台网推算。应用被系统彻底结束后无法接收推送。
