# 界面设计（Material Design 3 · 深色沉浸式）

## 布局：经典三栏

```text
┌──────────────────────────────────────────────────────────┐
│ 沉浸式标题栏（透明，叠加在内容之上）                       │
├────────┬──────────────────────────────────┬──────────────┤
│ 导航栏  │ 主内容（地图）                    │ 事件面板     │
│ 72px   │ 自适应                            │ 360px        │
│ 图标轨  │                                  │ 卡片列表     │
└────────┴──────────────────────────────────┴──────────────┘
```

- 左侧固定窄边栏：`NavigationRail`，图标 + 可选标签，选中有主题色圆角高亮。
- 中部为主内容，地图占满；顶部标题栏透明悬浮（沉浸式）。
- 右侧事件面板：卡片式列表，主事件大卡 + 子事件小卡。

## 配色（深色，非纯黑）

- 背景 `#15171A`（炭黑）
- 表面容器 `#1D2024` / `#262A30`
- 主色由 seed `#4C8DFF` 生成 MD3 色板
- 文字：标题 `#FFFFFF`，正文 `#E8EAED`，次要 `#9AA0A6`
- 语义色沿用震度色表（烈度 0–12 / JMA）

## 组件

- 圆角：卡片 16，控件 12，图标容器 12（柔和的中大圆角）
- 卡片层级：`Card`/`Container` 用 `surfaceContainer` 色 + 低透明度边框
- 排版：字重拉开层级，主信息白/高亮白，辅助信息低明度灰
